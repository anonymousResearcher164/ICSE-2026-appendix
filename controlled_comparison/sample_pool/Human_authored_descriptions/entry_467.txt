1: The robot starts from idle state, possibly picks an object. It has the destination address and moves the object to that location. If the move is finished, the method “move_base_finished” is called. 2: pose_queue_size means that there are more objects to move in the queue. The robot can move objects until the list is empty, bringing it to the idle state “move_base idle”.3: The robot waits for 3s or 3 minutes.4: Now it needs to return the object. It will need an address to return the object. When it returns the object,” move_base_finished” is called and it moves to idle state again “move_base_idle”.5: The robot waits for 3s or 3 mintues. 6: At the very end robot goes to “stand by object” mode.However, the fallback node considers if the first sequence node fails, it should try second sequence node, and if that fails, it should try the action node. Which means it should not move the object, just stand by the object.
