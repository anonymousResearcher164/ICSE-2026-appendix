The mission describes fallback behavior for moving or returning an object, waiting, and entering standby.

First, the robot will execute the first Sequence, the second Sequence, and custom action StandbyObject
consecutively. If the first Sequence fails, it will move to the second Sequence. If the second Sequence fails, it
will execute custom action StandbyObject. If no action succeeds, the fallback execution will fail.

Next, it will execute custom action MoveObject followed by custom action WaitObject in order. The sequence will
stop if either action fails.

Then, it will execute custom action ReturnObject followed by custom action WaitObject in order. The sequence will
stop if either action fails.

Finally, it will execute custom action StandbyObject.

Parameters: Custom action MoveObject will store its action output under {action}, read {move_base_finished}, read
{move_base_idle}, and read {pose_queue_size}. Custom action WaitObject will store its action output under {action}
and use a wait duration of 3. Custom action ReturnObject will store its action output under {action}, read
{home_pose_far}, read {move_base_finished}, and read {move_base_idle}. Custom action StandbyObject will store its
action output under {action}.
