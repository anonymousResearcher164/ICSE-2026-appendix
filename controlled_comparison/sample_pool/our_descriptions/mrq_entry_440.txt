The mission describes a robot repeatedly detecting human poses on the left and right and producing corresponding
speech messages.

First, the robot will execute the contained sequence 9999 times.

Next, it will execute the left-pose subtree followed by the right-pose subtree in order. The sequence will stop if
either subtree fails.

Then, it will execute the left-pose fallback. It will first execute the HumanPoseDetect action with empty expected
left and right poses and store the detected speech values in the pose_left_speech and pose_right_speech blackboard
keys. If this action fails, it will execute the Script action with the code full_left_msg := 'Left, ' +
pose_left_speech. If the Script action also fails, it will execute the TextToSpeechActionClient action with the
message full_left_msg.

Next, it will execute the right-pose fallback. It will first execute the HumanPoseDetect action with empty
expected left and right poses and store the detected speech values in the pose_left_speech and pose_right_speech
blackboard keys. If this action fails, it will execute the Script action with the code full_right_msg := 'Right, '
+ pose_right_speech. If the Script action also fails, it will execute the TextToSpeechActionClient action with the
message full_right_msg.
