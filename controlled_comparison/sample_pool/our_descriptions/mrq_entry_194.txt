The mission describes a sequence that starts a thought process, generates an answer, and says that answer.

First, the robot will execute the following actions in order. It will execute custom action SaySomething with
message "Start thinking...". It will execute custom action ThinkWhatToSay with text stored under the_answer. It
will execute custom action SaySomething with message read from the_answer. It will stop the sequence if any action
fails.
