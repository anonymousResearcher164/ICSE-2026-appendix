The mission describes a sequential behavior that announces a starting message, generates an answer, and announces
the answer.

First, the root Sequence will execute the actions in order and stop the sequence if any action fails.

Next, The robot will execute the custom action SaySomething to announce the starting message.

Then, it will execute the custom action ThinkWhatToSay to generate an answer.

Finally, it will execute the custom action SaySomething to announce the generated answer.

Parameters: The first custom action SaySomething will use the literal message "Start thinking...". The custom
action ThinkWhatToSay will store its output from the text port under the blackboard key {the_answer}. The second
custom action SaySomething will use the message read from the blackboard key {the_answer}.
