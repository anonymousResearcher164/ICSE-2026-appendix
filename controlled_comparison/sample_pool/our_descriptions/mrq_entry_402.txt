The mission describes initialization, repeated human-pose detection, image saving, speech, antenna signaling, and
delayed blackboard updates.

First, the robot will execute the first Sequence and the KeepRunningUntilFailure in order. It will stop the root
sequence if either child fails.

Next, it will execute the SetBlackboard actions in order. It will store TouchingNeck under pose_name_l, store
TouchingNeck under pose_name_r, store any under pose_lr_check, and execute the first AntennaAction. It will stop
this sequence if any action fails.

Next, it will execute the KeepRunningUntilFailure child. If its child succeeds, it will restart that child. If its
child fails, it will stop looping and continue the root sequence.

Next, it will execute the Sequence inside KeepRunningUntilFailure in order. It will execute ForceSuccess followed
by the second Sequence. It will stop this sequence if either child fails.

Next, it will execute the ForceSuccess child and make sure it always succeeds.

Next, it will execute the Sequence inside ForceSuccess in order. It will detect the specified human pose, execute
the third AntennaAction, save an image, announce Saved, and execute the fourth AntennaAction. It will stop this
sequence if any action fails.

Next, it will execute the second Sequence. It will execute the delayed SetBlackboard action after the delay timer.
The delay will last 1000 milliseconds before it stores 0 under dummy.

Parameters: The first AntennaAction will use rate 0, intensity 0, left_blink_pattern 0, and right_blink_pattern 0.

The HumanPoseDetect action will read expected_pose_left from pose_name_l, read expected_pose_right from
pose_name_r, read pose_lr_check from pose_lr_check, store its detected person under detected_person, store its
left-pose speech under pose_left_speech, and store its right-pose speech under pose_right_speech.

The second AntennaAction will use rate 0, intensity 10, left_blink_pattern 10, and right_blink_pattern 10.

The third AntennaAction will use rate 0, intensity 0, left_blink_pattern 0, and right_blink_pattern 0.
