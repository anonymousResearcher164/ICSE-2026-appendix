The mission describes a robot repeatedly returning to a rest pose, filling a tray from a table, and filling a shelf
from the tray.

First, the root Sequence will execute the FullCompetitionMode subtree in order and stop if that subtree fails. It
will repeat this execution indefinitely because the FullCompetitionMode subtree is inside a Repeat node with no
cycle limit.

Next, the FullCompetitionMode Repeat node will execute its Sequence indefinitely. The Sequence will execute
GetInRestPose followed by DoYourTrick and will stop if either subtree fails.

Then, the GetInRestPose Sequence will execute GetArmJointsForPose, followed by a Parallel node. The Parallel node
will execute a HeadControl and a TorsoControl in one sequence, SetArmJointsLeft, and SetArmJointsRight
simultaneously. It will succeed when three child actions succeed and will fail when three child actions fail.

Next, the DoYourTrick Repeat node will execute its Sequence indefinitely. The Sequence will execute the
FillYourTray subtree and the FillTheShelf subtree in order. Each subtree will be forced to succeed regardless of
its execution result.

Then, the FillYourTray Sequence will execute GoToTable, ScanTable, TorsoControl, HeadControl, and an unlimited
Repeat node in order. The Repeat node will repeatedly execute a Sequence that checks whether the table tray is
empty, checks whether the back tray is not full, and attempts to fill the back tray with the right arm. The first
nested Sequence will store table as the tray value, store RIGHT as the side value, and execute TrayIsEmpty. The
Inverter will reverse the result of the next Sequence, which will store backtray as the tray value and execute
TrayIsFull. The final ForceSuccess node will execute a Sequence that stores table as the source tray, stores
backtray as the destination tray, and executes RightArmFillYourTray. The final Sequence will be forced to succeed.

Next, the GoToTable Sequence will execute two MoveBase actions in order and will stop if either action fails.

Then, the ScanTable RetryUntilSuccessful node will repeatedly execute its Sequence until the sequence succeeds. The
Sequence will raise the torso, position the head, pause, start scanning the table, pause again, clear the octomaps,
obtain detected tomato cans, mark the table locations as occupied, and update the planning scene.

Next, the ClearAllOctomaps ForceSuccess node will execute a Sequence that clears the left octomap and the right
octomap. The sequence will be forced to succeed.

Then, the FillTheShelf Sequence will execute GetInRestPose, GoToShelves, ScanShelves, UpdateOctomap, TorsoControl,
HeadControl, and an unlimited Repeat node in order. The Repeat node will repeatedly execute a Sequence that checks
whether the back tray is empty, checks whether the shelf is not full, and attempts to fill the shelf with the left
arm. The first nested Sequence will store backtray as the tray value, store LEFT as the side value, and execute
TrayIsEmpty. The Inverter will reverse the result of the next Sequence, which will store shelf as the tray value
and execute TrayIsFull. The final ForceSuccess node will execute a Sequence that stores backtray as the source
tray, stores shelf as the destination tray, and executes LeftArmFillYourTray. The final Sequence will be forced to
succeed.

Next, the GoToShelves Sequence will execute two MoveBase actions in order and will stop if either action fails.

Then, the ScanShelves Sequence will raise the torso, position the head, pause, scan the shelves, mark the shelf
locations as unoccupied, and update the planning scene in order. It will stop if any action fails.

Next, the UpdateOctomap ForceSuccess node will execute a Sequence that clears both octomaps, positions the head at
one angle, and positions the head at another angle. The sequence will be forced to succeed.

Then, the LeftArmFillYourTray Sequence will pick an occupied locus from the source tray with the left arm. Its
Fallback node will first execute a Sequence that picks an empty locus from the destination tray, attempts to update
the planning scene, picks and places the object with the left arm, marks the source locus as unoccupied, marks the
destination locus as occupied, and releases the destination locus. If this sequence fails, the Fallback node will
execute a ForceFailure node that releases the destination locus. If no empty destination locus can be picked, the
outer Fallback node will execute a ForceFailure node that releases the source locus. The sequence will then release
the source locus.

Next, the RightArmFillYourTray Sequence will pick an occupied locus from the source tray with the right arm. Its
Fallback node will first execute a Sequence that picks an empty locus from the destination tray, attempts to update
the planning scene, picks and places the object with the right arm, marks the source locus as unoccupied, marks the
destination locus as occupied, and releases the destination locus. If this sequence fails, the Fallback node will
execute a ForceFailure node that releases the destination locus. If no empty destination locus can be picked, the
outer Fallback node will execute a ForceFailure node that releases the source locus. The sequence will then release
the source locus.

Next, the TrayIsFull Inverter will execute a Sequence that tries to pick an empty locus from the tray with the left
arm or the right arm and then forcefully releases the selected locus. The Inverter will reverse the result of this
sequence, so the subtree will succeed when no empty locus can be picked.

Next, the TrayIsEmpty Fallback node will execute a Sequence that tries to pick an occupied locus from the tray with
the specified side, forcefully releases that locus, and executes AlwaysSuccess. If this sequence fails, it will
execute AlwaysFailure.
