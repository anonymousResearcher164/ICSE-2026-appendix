The mission describes checking the battery, opening the gripper, approaching an object, and closing the gripper.

First, the root sequence will execute the following actions in order and stop the sequence if any action fails. The
robot will execute the custom action CheckBattery. It will then execute the custom action OpenGripper. It will next
execute the custom action ApproachObject. It will finally execute the custom action CloseGripper.

Parameters: None of the actions has ports.
