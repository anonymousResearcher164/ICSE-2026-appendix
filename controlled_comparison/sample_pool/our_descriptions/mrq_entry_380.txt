The mission describes a sequential behavior that checks whether the robot is full, moves to the closest resource,
and waits for 15 frames.

First, the Sequence Sequence1 will execute the following actions in order and stop the sequence if any action
fails. The robot will check whether isFull is true. It will execute custom action goClosestR. It will execute
custom action waitFrames.

Parameters: The custom action waitFrames will use barout="", baz="", fooin="", and frames="15".
