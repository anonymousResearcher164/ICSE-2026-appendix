The mission describes charging at a charging station and leaving the station after charging.

First, the robot will execute the ChargeST subtree.

Next, it will execute the actions in the ChargeST SequenceStar in order. If an action succeeds, it will remember
that action and move to the next action. If an action fails, it will restart the sequence from the failed action.
It will first execute Speak, then Wait2Seconds, then the Fallback, then WaitForXSeconds, then Speak, and finally
Charge with action STOP_CHARGE and action_name charging_action.

Next, it will execute the single child of the Fallback consecutively. If the child fails, the Fallback will fail
because no alternative child remains.

Next, it will execute the actions in the inner SequenceStar in order. If an action succeeds, it will remember that
action and move to the next action. If an action fails, it will restart the sequence from the failed action. It
will first execute RetryUntilSuccesful and then the Parallel.

Next, it will execute ROS action MoveBase through RetryUntilSuccesful. If the action fails, it will re-execute it
up to three attempts or until it succeeds.

Next, it will execute ROS action Charge and the Repeat simultaneously through the Parallel. If both actions
succeed, the Parallel will succeed. If either action fails, the Parallel will fail.

Next, it will execute Speak through the Repeat five times.

Next, it will wait for two seconds through Wait2Seconds.

Next, it will execute Speak to announce that it is full and will leave the station.

Next, it will execute Charge with action STOP_CHARGE and action_name charging_action.

Parameters: The first Speak action will use action_name /gcloud_tts, language pt_PT, utterance Tenho fome, and
voice pt-PT-Wavenet-D. The MoveBase action will use action_name move_base, frame_id map, and goal_pose
-1.7971;-5.5118;0.0;0;0;0.72703;0.68659. The repeated Speak action will use action_name /gcloud_tts, language
pt_PT, utterance bip bip, and voice pt-PT-Wavenet-D.
