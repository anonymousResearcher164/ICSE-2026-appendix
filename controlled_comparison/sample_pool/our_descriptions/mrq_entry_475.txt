The mission describes a robot charging routine that starts with speaking, waits, charges, and then leaves the
charging station.

First, the root node will execute the ChargeST subtree.

Next, the robot will execute the actions in the ChargeST sequence from left to right. If an action succeeds, it
will remember that action and move to the next action. If an action fails, it will restart the sequence from the
failed action.

Then, it will speak that it is hungry.

Next, it will wait for two seconds.

Then, it will execute the fallback. If the first action sequence fails, it will proceed to the next action. If no
action succeeds, the fallback will fail.

Next, it will execute the first nested sequence. If an action succeeds, it will remember that action and move to
the next action. If an action fails, it will restart the sequence from the failed action.

Then, it will keep trying the ROS action MoveBase until it succeeds or until it has made three attempts.

Next, it will execute the ROS action MoveBase.

Then, it will execute the Parallel node by charging and speaking simultaneously. The parallel execution will
succeed when two actions succeed. It will fail if any action fails.

Next, it will execute the Charge action.

At the same time, it will repeat the Speak action five times.

Then, it will wait for ten seconds.

Next, it will speak that it is full and will leave the station.

Finally, it will stop charging.

Parameters: The first Speak action will use action_name "/gcloud_tts", language "pt_PT", utterance "Tenho fome",
and voice "pt-PT-Wavenet-D". The first WaitForXSeconds action will use result "SUCCESS" and seconds "2". The
MoveBase action will use action_name "move_base", frame_id "map", and goal_pose
"-1.7971;-5.5118;0.0;0;0;0.72703;0.68659". The Charge action will use action "CHARGE" and action_name
"charging_action". The repeated Speak action will use action_name "/gcloud_tts", language "pt_PT", utterance "bip
bip", and voice "pt-PT-Wavenet-D". The second WaitForXSeconds action will use result "SUCCESS" and seconds "10".
The second Speak action will use action_name "/gcloud_tts", language "pt_PT", utterance "Estou cheio, vou sair da
estação", and voice "pt-PT-Wavenet-D". The final Charge action will use action "STOP_CHARGE" and action_name
"charging_action".
