The mission describes navigating a robot to a specified goal while recovering from navigation failures.

First, the robot will execute the main action PipelineSequence NavigateWithReplanning. If it fails, it will
execute the recovery action ReactiveFallback RecoveryFallback. After recovery, it will retry the main action. If
recovery fails and six retries are exhausted, it will stop execution.

Next, it will execute the actions RateController and RecoveryNode FollowPath in order. It will stop the sequence
if any action fails. While an action is running or has succeeded, it will proceed to the next action.

Then, it will execute RateController around RecoveryNode ComputePathToPose.

Next, it will execute the main action ComputePathToPose with the goal read from {goal}, store the resulting path
under {path}, and use the planner identifier GridBased. If it fails, it will execute ClearEntireCostmap
ClearGlobalCostmap-Context with the service name global_costmap/clear_entirely_global_costmap. After recovery, it
will retry the main action. If recovery fails and one retry is exhausted, it will stop execution.

Then, it will execute the main action FollowPath with the path read from {path} and use the controller identifier
FollowPath. If it fails, it will execute ClearEntireCostmap ClearLocalCostmap-Context with the service name
local_costmap/clear_entirely_local_costmap. After recovery, it will retry the main action. If recovery fails and
one retry is exhausted, it will stop execution.

Finally, it will execute the recovery action ReactiveFallback RecoveryFallback. It will execute GoalUpdated and
SequenceStar RecoveryActions in order. If GoalUpdated succeeds, it will stop execution. Otherwise, it will
continue with SequenceStar RecoveryActions and re-evaluate GoalUpdated whenever a later action is running. If
GoalUpdated then succeeds, it will halt the running action and stop the fallback.

Next, it will execute ClearEntireCostmap ClearLocalCostmap-Subtree, ClearEntireCostmap ClearGlobalCostmap-Subtree,
Spin, and Wait in sequence. If any action succeeds, it will remember it and move to the next action. If any action
fails, it will start the sequence again from the failed action.

Then, it will execute ClearEntireCostmap ClearLocalCostmap-Subtree with the service name
local_costmap/clear_entirely_local_costmap.

Next, it will execute ClearEntireCostmap ClearGlobalCostmap-Subtree with the service name
global_costmap/clear_entirely_global_costmap.

Then, it will execute Spin with a spin distance of 1.57.

Finally, it will execute Wait with a wait duration of 5.
