The mission describes navigating to a goal while periodically replanning the path.

First, the robot will execute path computation and path following in order and stop the sequence if either action
fails. While an action is running or has succeeded, it will proceed to the next action.

Next, it will run ROS action ComputePathToPose at a rate of 1.0 Hz. The action will read the goal from key goal,
store the computed path under key path, and use GridBased as the planner identifier.

Finally, it will run ROS action FollowPath. The action will read the path from key path and use FollowPath as the
controller identifier.
