The mission describes a pipeline that repeatedly plans and follows a path to a goal while updating the goal and
truncating the planned path.

First, the PipelineSequence NavigateWithReplanning will execute the RateController and the KeepRunningUntilFailure
in order. While the RateController is running or has succeeded, it will proceed to the KeepRunningUntilFailure. It
will stop the pipeline if either action fails.

Next, the ROS action RateController will execute its child at a rate of 1.0 Hz.

Then, the Sequence will execute the GoalUpdater and the TruncatePath in order. It will stop if either action fails.

Next, the GoalUpdater will execute the ComputePathToPose action using the updated goal.

Finally, the ComputePathToPose action will calculate a path, and the TruncatePath action will shorten that path to
a distance of 1.0.

Next, the KeepRunningUntilFailure will execute the FollowPath action. If the FollowPath action succeeds, it will
restart the action. If the FollowPath action fails, it will stop looping and continue execution.

Parameters: The ComputePathToPose action will read the goal from {updated_goal}, store the resulting path under
{path}, and use GridBased as the planner identifier. The TruncatePath action will use 1.0 as the distance, read
the input path from {path}, and store the truncated path under {truncated_path}.
