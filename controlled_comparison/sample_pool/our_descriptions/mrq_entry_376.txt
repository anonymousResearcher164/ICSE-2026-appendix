The mission describes a repeated social interaction behavior that combines dialogue with social navigation.

First, the root sequence will execute the Repeat action and stop the sequence if the Repeat action fails.

Next, the robot will execute the Parallel action 100 times.

Then, it will execute the Dialog action and the ROS action SocialNav2Action simultaneously. If one action
succeeds, the Parallel action will succeed. If any action fails, the Parallel action will fail.
