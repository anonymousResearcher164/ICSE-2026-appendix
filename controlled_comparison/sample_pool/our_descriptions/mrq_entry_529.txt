The mission describes navigation to a goal with path computation and path following.

First, the robot will execute NavigateWithReplanning as a pipeline sequence. It will execute DistanceController and
then FollowPath in order. It will advance to the next action while the current action is running or has succeeded.
It will stop the sequence if an action fails.

Next, it will execute DistanceController with ComputePathToPose as its child.

Then, it will execute ComputePathToPose to compute a path to the goal.

Finally, it will execute FollowPath to follow the computed path.

Parameters: ComputePathToPose will read the goal from {goal}, store the resulting path under {path}, and use
GridBased as the planner_id.

Parameters: FollowPath will read the path from {path} and use FollowPath as the controller_id.

Parameters: DistanceController will use 1.0 as the distance.
