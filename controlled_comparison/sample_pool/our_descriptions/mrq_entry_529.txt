The mission describes navigation to a goal with replanning and path following.

First, the pipeline sequence NavigateWithReplanning will execute the ROS action DistanceController and then the
ROS action FollowPath in order. It will stop if an action fails. While an action is running or has succeeded, it
will proceed to the next action.

Next, the ROS action DistanceController will use a distance of 1.0 and execute the ROS action ComputePathToPose.

Finally, the ROS action FollowPath will follow the path read from the path key using the FollowPath controller.

Parameters: The ROS action ComputePathToPose will use the goal read from the goal key, store the computed path
under the path key, and use the GridBased planner.
