The mission describes conditional movement between a shed and pasture according to time and location.

First, the robot will execute the first SequenceStar, the second SequenceStar, and the third SequenceStar
consecutively. If any sequence fails, it will move to the next sequence until one succeeds. If all sequences fail,
it will start again from the first sequence until one succeeds.

Next, it will execute IsOnPasture, IsDay, IsInShed, LeaveShed, FindRandomPastureField, and Move in sequence. After
a node succeeds, it will remember that node and move to the next node. If a node fails, it will restart the
sequence from that failed node.

Next, it will execute IsOnPasture, IsNight, inverted IsInShed, FindShed, Move, and EnterShed in sequence. After a
node succeeds, it will remember that node and move to the next node. If a node fails, it will restart the sequence
from that failed node. The inverted IsInShed condition will fail when IsInShed is true and will succeed when
IsInShed is false.

Finally, it will execute IsDay, inverted IsInShed, and RandomMove in sequence. After a node succeeds, it will
remember that node and move to the next node. If a node fails, it will restart the sequence from that failed node.
The inverted IsInShed condition will fail when IsInShed is true and will succeed when IsInShed is false.
