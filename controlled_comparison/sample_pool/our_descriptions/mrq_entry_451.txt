The mission describes a robot that will acquire a target, move toward it, and attack it when adjacent, with random
movement as a fallback.

First, the robot will execute the main sequence and use random movement if the main sequence fails. If the main
sequence succeeds, it will not execute random movement. If both actions fail, the fallback will fail.

Next, it will execute GetTarget, Move, and the nested sequence in order while remembering successful actions. If
an action fails, it will restart the sequence from that action.

Then, it will check whether TargetAdjacent is true and will execute AttackTarget if the condition succeeds. If the
condition fails, the sequence will stop.

Finally, it will execute RandomMove when the main sequence fails.
