The mission describes selecting and approaching a target, attacking it when the target is adjacent, or moving
randomly.

The robot will execute the fallback. If the first action fails, it will execute custom action RandomMove. If no
action succeeds, the fallback will fail.

Next, it will execute custom actions GetTarget, Move, and the sequence in order. If an action succeeds, it will
remember that action and move to the next one. If an action fails, it will restart the sequence from the failed
action.

Finally, it will execute the sequence by checking whether TargetAdjacent is true and then executing custom action
AttackTarget.
