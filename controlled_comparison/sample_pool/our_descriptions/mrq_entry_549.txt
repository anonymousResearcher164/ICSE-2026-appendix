The mission describes a sequence that moves the arm to a specified pose.

First, the root Sequence will execute the custom action ExecuteGroupPose in order and stop the sequence if the
action fails. The robot will perform this action.

Parameters: It will use goal "0 0 0 0 0 0 1" for the pose. It will use group_name "arm". It will use is_absolute
"0". It will use service_name "execute_group_pose". It will use tolerance "0.01".
