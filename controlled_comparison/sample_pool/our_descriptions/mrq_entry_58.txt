The mission describes a sequential behavior for executing go1 followed by go2.

First, the root Sequence will execute the first nested Sequence and custom action go2 in order and stop the
sequence if any action fails.

Next, the robot will execute the second nested Sequence in order and stop the sequence if any action fails.

Then, it will execute the third nested Sequence in order and stop the sequence if any action fails.

Finally, it will execute custom action go1 and stop the sequence if the action fails.
