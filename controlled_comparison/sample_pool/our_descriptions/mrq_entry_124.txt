The mission describes a robot arm that will construct a collision scene and move a box from the center to the left
and right sides.

First, the root sequence will execute the sequence add collisions, add the box surface, the left repeat operation,
and the right repeat operation in order and will stop if any operation fails. The robot will execute these
operations sequentially.

Next, the sequence add collisions will execute Add groud to scene, Add left wall, Add right wall, Add top wall,
and Add conveyor in order and will stop if any action fails.

Then, it will add a ground plane to the scene.

Next, it will add the left wall to the scene.

Next, it will add the right wall to the scene.

Next, it will add the top wall to the scene.

Finally, it will add the conveyor to the scene.

Next, it will add the box surface after the collision objects have been added.

Next, the first repeat node will execute its child sequence once.

Then, the sequence left will execute pre middle left, remove boxes_surface, pick, lift up, pull out, post middle
left, place, post middle left, and box_surface in order and will stop if any action fails.

Next, it will move the arm to the pre middle left joint state.

Next, it will remove the boxsur object from the scene.

Next, it will move the arm through the pick pose.

Next, it will shift the arm upward by 0.1 along the z-axis.

Next, it will shift the arm by -0.4 along the x-axis.

Next, it will move the arm to the post middle left joint state.

Next, it will move the arm to the place joint state.

Next, it will move the arm back to the post middle left joint state.

Finally, it will add the box surface back to the scene.

Next, the second repeat node will execute its child sequence once.

Then, the sequence right will execute pre middle right, remove the boxsur object, pick, lift up, pull out, post
middle left, place left, post middle left, and boxes_surface in order and will stop if any action fails.

Finally, it will add the box surface back to the scene.
