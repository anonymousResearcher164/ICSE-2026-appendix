The mission describes a robot arm that will construct a collision scene and move objects from both sides into
designated locations.

First, the root sequence will execute the add collisions sequence, add a box surface, repeat the left-side
manipulation sequence once, and repeat the right-side manipulation sequence once. The sequence will stop if any
action fails.

Next, the add collisions sequence will add a ground plane, a left wall, a right wall, a top wall, and a conveyor.
The sequence will stop if any action fails.

Then, the left-side sequence will move the arm to the left pre-middle position. It will remove the box surface. It
will move to the left picking pose. It will lift the object along the z-axis. It will pull the object along the
negative x-axis. It will move to the left post-middle position. It will move to the left placing position. It will
return to the left post-middle position. It will restore the box surface. The sequence will stop if any action
fails.

Finally, the right-side sequence will move the arm to the right pre-middle position. It will remove the box
surface. It will move to the right picking pose. It will lift the object along the z-axis. It will pull the object
along the negative x-axis. It will move to the right post-middle position. It will move to the right placing
position. It will return to the right post-middle position. It will restore the box surface. The sequence will stop
if any action fails.
