The mission describes navigating to a dynamic pose while continuously replanning the path and following it.

First, the PipelineSequence named NavigateWithReplanning will execute the RateController and the
KeepRunningUntilFailure in order. It will advance to the next child while the current child is running or has
succeeded. It will stop if a child fails.

Next, the RateController will execute its child sequence at a rate of 2.0 Hz.

Then, the Sequence will execute the GoalUpdater in order and stop if the GoalUpdater fails.

Next, the GoalUpdater will update the navigation goal from {goal} and store the updated goal under {updated_goal}.
It will execute the ComputePathToPose using the updated goal.

Then, the ComputePathToPose will calculate a path and store it under {path}.

Finally, the KeepRunningUntilFailure will execute the FollowPath. If the FollowPath succeeds, it will restart it.
If the FollowPath fails, it will stop looping and continue execution.

Parameters: The ComputePathToPose will use the planner identifier GridBased. The FollowPath will use {path} as its
path input. The FollowPath will use the controller identifier FollowPath.
