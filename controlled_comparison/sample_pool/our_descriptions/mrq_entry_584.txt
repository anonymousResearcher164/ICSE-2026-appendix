The mission describes navigating toward a dynamically updated goal pose.

First, the robot will execute the following actions in order and advance to the next action while an action is
running or has succeeded. It will stop the sequence if any action fails.

Next, it will execute the first child at a rate of 2.0 Hz. It will execute the actions in the child sequence in
order and stop the sequence if any action fails. It will use the custom action GoalUpdater with the goal read from
{goal} and store the updated goal under {updated_goal}. It will then execute the ROS action ComputePathToPose with
the goal read from {updated_goal}, store the resulting path under {path}, and use the planner ID GridBased.

Finally, it will execute the custom action KeepRunningUntilFailure with the ROS action FollowPath using the path
read from {path} and the controller ID FollowPath. If the action succeeds, it will restart it. If the action
fails, it will stop looping and continue execution.
