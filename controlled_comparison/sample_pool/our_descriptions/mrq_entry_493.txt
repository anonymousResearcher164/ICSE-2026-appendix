The mission describes automatic localization of the robot.

First, the robot will execute initialPoseReceived and doSelfLocalization consecutively until one action succeeds.
If both actions fail, it will start again with initialPoseReceived.

Next, it will execute custom action initialPoseReceived.

Finally, it will execute sequence doSelfLocalization. If retry_client_request succeeds, it will remember that
success and continue with retry_localization. If an action fails, it will restart the sequence from that failed
action.

First, it will continuously execute custom action globalLocalizationServiceRequest until it succeeds, for up to
five attempts.

Next, it will continuously execute the localization sequence until it succeeds, for up to ten attempts.

First, it will execute the fallback containing IsLocalized and the localization recovery sequence. If IsLocalized
succeeds, it will stop the fallback. If IsLocalized fails, it will execute the localization recovery sequence. If
all fallback actions fail, the fallback will fail.

Next, it will execute Spin, BackUp, and Spin in order while remembering successful actions. If an action fails, it
will restart the sequence from that failed action.

Finally, it will execute custom action IsLocalized.
