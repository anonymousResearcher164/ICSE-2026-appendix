The mission describes placing an object at a pose determined from the object.

First, the sequence place will execute its actions in order and stop if any action fails. The robot will execute
custom action GetPickObject to obtain the object identified by the value read from the object_id key. It will
execute custom action GetPlacingPose with the object identified by the value read from the object_id key. It will
store the resulting placing pose under the pose key. It will execute custom action ApproachObject using the pose
read from the pose key. It will execute custom action PlaceSimple using the pose read from the pose key.
