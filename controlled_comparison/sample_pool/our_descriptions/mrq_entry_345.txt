The mission describes a sequence that obtains joint configurations for four arm poses and applies each
configuration to both arms.

The sequence will execute the following actions in order and stop the sequence if any action fails.

First, the robot will execute custom action GetArmJointsForPose with pose set to UPTRAY and store the resulting
joint configuration under joints_pose.

Next, it will execute custom action SetArmJointsLeft using the joint configuration read from joints_pose.

Next, it will execute custom action SetArmJointsRight using the joint configuration read from joints_pose.

Next, it will execute custom action GetArmJointsForPose with pose set to EXTENDED and store the resulting joint
configuration under joints_pose.

Next, it will execute custom action SetArmJointsLeft using the joint configuration read from joints_pose.

Next, it will execute custom action SetArmJointsRight using the joint configuration read from joints_pose.

Next, it will execute custom action GetArmJointsForPose with pose set to GRIPPING and store the resulting joint
configuration under joints_pose.

Next, it will execute custom action SetArmJointsLeft using the joint configuration read from joints_pose.

Next, it will execute custom action SetArmJointsRight using the joint configuration read from joints_pose.

Next, it will execute custom action GetArmJointsForPose with pose set to REST and store the resulting joint
configuration under joints_pose.

Next, it will execute custom action SetArmJointsLeft using the joint configuration read from joints_pose.

Finally, it will execute custom action SetArmJointsRight using the joint configuration read from joints_pose.
