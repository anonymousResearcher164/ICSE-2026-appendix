The mission describes the robot moving its arms through the UPTRAY, EXTENDED, GRIPPING, and REST poses.

First, the robot will execute the actions in order and stop the sequence if any action fails. It will obtain the
arm joints for the UPTRAY pose. It will set the left arm joints. It will set the right arm joints. It will obtain
the arm joints for the EXTENDED pose. It will set the left arm joints. It will set the right arm joints. It will
obtain the arm joints for the GRIPPING pose. It will set the left arm joints. It will set the right arm joints. It
will obtain the arm joints for the REST pose. It will set the left arm joints. It will set the right arm joints.

Parameters: GetArmJointsForPose will receive pose="UPTRAY" and store its result under {joints_pose}.
SetArmJointsLeft will read {joints_pose}. SetArmJointsRight will read {joints_pose}. GetArmJointsForPose will
receive pose="EXTENDED" and store its result under {joints_pose}. SetArmJointsLeft will read {joints_pose}.
SetArmJointsRight will read {joints_pose}. GetArmJointsForPose will receive pose="GRIPPING" and store its result
under {joints_pose}. SetArmJointsLeft will read {joints_pose}. SetArmJointsRight will read {joints_pose}.
GetArmJointsForPose will receive pose="REST" and store its result under {joints_pose}. SetArmJointsLeft will read
{joints_pose}. SetArmJointsRight will read {joints_pose}.
