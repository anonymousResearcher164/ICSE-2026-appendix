The mission describes navigating to a goal while recomputing the path, following the path, and performing recovery
actions when navigation fails.

First, The robot will execute the main navigation subtree. If the main navigation subtree fails, it will execute
the recovery subtree. After recovery, it will retry the main navigation subtree until six recovery attempts are
exhausted. If recovery fails after the retries are exhausted, it will stop execution.

Next, it will execute the actions in NavigateWithReplanning in order and stop if any action fails. While an action
is running or has succeeded, it will proceed to the next action.

Then, ROS action RateController will execute ComputePathToPose at a rate of 1.0 hertz.

Next, it will execute the main ComputePathToPose action. If that action fails, it will execute
ClearGlobalCostmap-Context. After recovery, it will retry ComputePathToPose once. If recovery fails and the retry
is exhausted, it will stop execution.

Then, ROS action ComputePathToPose will compute a path.

Next, it will execute the main FollowPath action. If that action fails, it will execute ClearLocalCostmap-Context.
After recovery, it will retry FollowPath once. If recovery fails and the retry is exhausted, it will stop
execution.

Then, ROS action FollowPath will follow the computed path.

Next, it will execute the actions in RecoveryFallback in order. If GoalUpdated succeeds, it will stop the recovery
sequence. Otherwise, it will execute RecoveryActions. While RecoveryActions is running, it will re-evaluate
GoalUpdated. If GoalUpdated succeeds during recovery, it will halt the running recovery action and stop the
fallback.

Then, it will execute the actions in RecoveryActions in sequence. If an action succeeds, it will remember that
action and move to the next action. If an action fails, it will restart the sequence from the failed action.

Next, ROS action ClearLocalCostmap-Subtree will clear the local costmap.

Then, ROS action ClearGlobalCostmap-Subtree will clear the global costmap.

Next, ROS action Spin will rotate it by 1.57 radians.

Finally, ROS action Wait will wait for 5 seconds.

Parameters: ROS action ComputePathToPose will read goal from {goal}, store the resulting path under {path}, and
use the literal planner ID GridBased.
