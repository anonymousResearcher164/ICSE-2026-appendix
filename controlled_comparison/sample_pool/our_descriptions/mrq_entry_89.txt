The mission describes computing a path to a goal pose and following that path.

First, the robot will execute ROS action ComputePathToPose followed by ROS action FollowPath in order and stop the
sequence if either action fails.

Parameters: It will provide the goal read from {goal} to ROS action ComputePathToPose, store the resulting path
under {path}, and use GridBased as planner_id. It will provide the path read from {path} to ROS action FollowPath
and use FollowPath as controller_id.
