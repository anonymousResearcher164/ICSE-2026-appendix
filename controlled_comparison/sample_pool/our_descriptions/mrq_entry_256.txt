The mission describes a repeated sequence for checking and updating linear temporal logic states while moving the
robot.

First, the robot will execute the sequence {num_cycles} times.

Next, it will execute custom action LTLPreCheck, custom action MoveAction, and custom action UpdateLTL in order and
stop the sequence if any action fails.

Parameters: Custom action LTLPreCheck will read ltl_state_current from {ltl_state_current}. Custom action
LTLPreCheck will read ltl_state_desired_sequence from {ltl_state_desired_sequence}. Custom action MoveAction will
store its action under {action}. Custom action MoveAction will read move_base_finished from {move_base_finished}.
Custom action MoveAction will read move_base_idle from {move_base_idle}. Custom action MoveAction will read
nav_goal from {nav_goal}. Custom action UpdateLTL will read and update action_sequence in {action_sequence}. Custom
action UpdateLTL will read and update ltl_state_desired_sequence in {ltl_state_desired_sequence}. Custom action
UpdateLTL will store nav_goal under {nav_goal}.
