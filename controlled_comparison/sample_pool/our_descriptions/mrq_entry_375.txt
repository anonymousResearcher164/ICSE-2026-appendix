The mission describes checking whether the robot is full, moving to the closest resource, and waiting for 15
frames.

First, the robot will execute the condition isFull, the custom action goClosestR, and the custom action waitFrames
in order. It will stop the sequence if any action fails.

Parameters: The custom action waitFrames will use an empty value for barout. The custom action waitFrames will use
an empty value for baz. The custom action waitFrames will use an empty value for fooin. The custom action
waitFrames will use 15 for frames.
