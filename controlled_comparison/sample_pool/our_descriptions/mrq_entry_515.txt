The mission describes continuous handling of a variant while recognizing a person and obtaining the person's
position or moving to a specified position.

First, the parallel node will execute the repeat node and the sequence node simultaneously. It will succeed only
when all actions succeed, and it will fail if any action fails.

Next, the repeat node will execute custom action VariantAction continuously. The action will store its value under
{variant}.

Then, the sequence node will execute custom action peoplerecognition followed by the fallback node in order. It
will stop if any action fails.

Finally, the fallback node will execute custom action getPersonPose. If that action fails, it will execute custom
action moveRoboterPosition. If no action succeeds, the fallback will fail.

Parameters: custom action getPersonPose will use personname=THOMAS, store its x output under {x_}, store its y
output under {y_}, and store its z output under {z_}.

Custom action moveRoboterPosition will use approachRadius=200, x=3000, and y=-12000.
