The mission describes a sequential behavior that performs an action, checks a condition, and executes the
LotOfStuff subtree.

First, the root sequence will execute Action_A, Condition_B, and LotOfStuff in order. It will stop the sequence if
any action fails.

Next, it will execute custom action Action_A.

Then, it will execute custom action Condition_B.

Finally, it will execute custom action LotOfStuff.

Parameters: The input port of custom action Action_A will use the literal value 42. The result port of custom
action Condition_B will use the literal value 69. The res port of custom action LotOfStuff will use the literal
value 200. The param port of custom action LotOfStuff will use the literal value 100.
