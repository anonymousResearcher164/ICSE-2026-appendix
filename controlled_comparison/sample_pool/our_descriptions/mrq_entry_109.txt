The mission describes repeatedly navigating between two target poses.

First, the robot will execute the sequence ten times.

Next, it will execute the custom action NavigateToAction for the first target pose and then the custom action
NavigateToAction for the second target pose in order, stopping the sequence if either action fails.

Parameters: The first custom action NavigateToAction will use goal 0.5;0.5;0. The second custom action
NavigateToAction will use goal -0.5;-0.5;0.
