The mission describes generating grasp candidates from a tabletop scene.

First, the root sequence will execute the following actions in order and stop if any action fails. The robot will
first perform tabletop segmentation, then conditionally extract and cluster the desired object, and finally
generate grasping candidates.

Next, it will retry tabletop segmentation until it succeeds or three attempts have been made.

Then, the conditional sequence will execute object cloud extraction and tabletop clustering in order while
checking whether the False condition is true. If the False condition is false, it will end the sequence.

Next, the BlackboardEntryCheck decorator will check whether the desired object entry is available before executing
object cloud extraction.

Finally, it will generate grasping candidates.

Parameters: TableTopSegmentation will read original_cloud from the original_cloud key. TableTopSegmentation will
read image_scene from the image_scene key. TableTopSegmentation will read table_height from the table_height key.
TableTopSegmentation will store the transformed cloud under the original_cloud_transformed key.
TableTopSegmentation will store the tabletop cloud under the tabletop_cloud key. TableTopSegmentation will store
the plane cloud under the plane_cloud key. TableTopSegmentation will store the nonplane cloud under the
nonplane_cloud key. ObjectCloudExtraction will read original_cloud from the original_cloud key.
ObjectCloudExtraction will read image_scene from the image_scene key. ObjectCloudExtraction will store the object
cloud under the object_cloud key. ObjectCloudExtraction will read tabletop_cloud from the tabletop_cloud key.
ObjectCloudExtraction will read desired_object from the desired_object key. GenerateGraspingCandidates will read
object_cloud from the object_cloud key. GenerateGraspingCandidates will read table_height from the table_height
key. GenerateGraspingCandidates will store grasp candidates under the grasp_candidates key.
GenerateGraspingCandidates will read original_cloud_transformed from the original_cloud_transformed key.
